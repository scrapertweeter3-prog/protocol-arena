# Protocol Arena

A free browser game that prices home biohacking gear against paid
memberships on one number: cost per completed session. Both lanes run the
same 52 weeks at three sessions a week. Fixed costs bill every week
whether you show up or not; per-visit costs bill only on completed
sessions.

Three duels:

- Home sauna vs gym lounge (upfront unit plus electricity vs monthly
  dues and drop-in fees)
- Spin bike vs studio classes (bike plus pennies of power vs a monthly
  plan and per-class bookings)
- Home rack vs big-box gym (one-time rig vs cheap dues plus a commute
  cost per visit)

Pick a duel, set the seed, run the year. The verdict names the lane with
the lower cost per completed session and prints both totals.

Deterministic simulation: same seed, same year, every time. Built as a
single static page with no build step. MIT licensed.

Protocol and recovery ideas behind it live at
[hackedself.com](https://hackedself.com/).
